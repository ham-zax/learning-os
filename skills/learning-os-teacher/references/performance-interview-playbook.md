# Optional Interview & Mock Posture

Load only for `interview` or `mock` delivery contexts. Not a mandatory preflight.

## Uninterrupted performance & deferred debrief

During `interview` or `mock`, preserve uninterrupted performance when mid-attempt coaching would invalidate what is being measured:

```text
present task -> learner performs without coaching -> collect observable work -> assess -> debrief afterward
```

Defer answer-bearing explanation and reflection until the attempt closes. Useful debrief prompts ask where reasoning became uncertain, which assumption drove the key decision, and what evidence would have changed the approach. Never retrofit debrief quality into technical correctness or mastery state.
