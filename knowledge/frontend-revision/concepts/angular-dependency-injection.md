# Angular Dependency Injection and Provider Scope

## Summary
An injector resolves a dependency through its hierarchy. Provider placement determines instance ownership and lifetime, so the same service token need not mean the same instance everywhere.

## Common Misconceptions
- Assuming every injected service is a single application-wide object.

## Practice Questions
- Two component subtrees provide the same token. Which state should they share, and which should remain isolated?
