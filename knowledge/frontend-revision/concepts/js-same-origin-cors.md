# Same-Origin Policy and CORS

## Summary
Same-origin policy and CORS govern browser access across origins. A permitted cross-origin response does not establish user authorization. Specify credentials and server behavior separately.

## Common Misconceptions
- Treating CORS as an authentication system or expecting frontend headers to grant server permission.

## Practice Questions
- A response reaches the browser network panel but script cannot read it. Separate server execution from browser read access.
