# Closures

## Summary
A closure retains access to lexical bindings. Separate calls can create separate environments; multiple returned functions from one call can share a binding.

## Common Misconceptions
- Assuming every returned function captures an immutable snapshot, or putting per-instance state in module scope.

## Practice Questions
- Use the counter lab: explain which two operations must share a binding and which two instances must not.
