# JavaScript Types

## Summary
Values have types; bindings hold values. Assignment copies a primitive value or an object reference value. Mutating a shared object and rebinding one variable are different operations.

## Common Misconceptions
- Saying objects are passed by reference without distinguishing mutation from reassignment.
