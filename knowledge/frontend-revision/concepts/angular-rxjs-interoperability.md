# Angular RxJS and Signal Interoperability

## Summary
Signals expose current reactive values; observables model streams with subscription lifetimes and operators. Conversion does not remove cancellation, error or ownership decisions.

## Common Misconceptions
- Assuming converting a stream to a signal automatically solves all async races.

## Practice Questions
- Type-ahead changes quickly. Describe which stream work should be superseded and when the subscription must stop.
