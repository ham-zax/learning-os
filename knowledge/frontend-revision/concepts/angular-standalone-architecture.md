# Angular Standalone Architecture

## Summary
Make feature dependencies and provider boundaries explicit. Standalone components express their imports; application-level and component-level providers have different lifetimes.

## Common Misconceptions
- Using module terminology as a substitute for explaining actual dependency ownership.

## Practice Questions
- Move a feature between routes and explain which dependencies it must import and which service instances should survive.
