# Daily Session Template

## Pre-Session (2 min)
- [ ] Open today's concept file
- [ ] Open today's problems file
- [ ] Set timer for 2 hours
- [ ] Clear distractions

## Session A: Learn + Pseudocode (60 min)

### Concept Review (10 min)
- [ ] Read concept summary
- [ ] Review key points
- [ ] Study example patterns

### Problem 1: Pseudocode (20 min)
- [ ] Read problem statement
- [ ] Write pseudocode (don't skip this!)
- [ ] Identify data structures needed
- [ ] Analyze time/space complexity
- [ ] List edge cases

### Problem 2: Pseudocode (20 min)
- [ ] Read problem statement
- [ ] Write pseudocode
- [ ] Identify data structures needed
- [ ] Analyze time/space complexity
- [ ] List edge cases

### Quick Review (10 min)
- [ ] Compare your pseudocode to the patterns
- [ ] Make sure you can explain your approach
- [ ] Note any questions or confusions

## Session B: Implement + Debug (60 min)

### Problem 1: Implementation (25 min)
- [ ] Convert pseudocode to Python
- [ ] Run test cases
- [ ] Debug if needed
- [ ] If stuck > 10 min, check hint (not solution)

### Problem 2: Implementation (25 min)
- [ ] Convert pseudocode to Python
- [ ] Run test cases
- [ ] Debug if needed
- [ ] If stuck > 10 min, check hint (not solution)

### Review + Self-Assess (10 min)
- [ ] Compare to optimal solution
- [ ] Note what you learned
- [ ] Rate yourself 0-5 on the pattern
- [ ] Update progress tracker

## Post-Session (5 min)
- [ ] Update INDEX.md with status
- [ ] Write brief notes in journal
- [ ] Note any patterns you struggled with
- [ ] Set intention for tomorrow

## When You're Stuck

### Step 1: Re-read the problem
- Did you miss a constraint?
- Did you misunderstand the input/output?

### Step 2: Check your pseudocode
- Is the algorithm correct?
- Are you handling all edge cases?

### Step 3: Debug systematically
- Add print statements
- Trace through a small example
- Check boundary conditions

### Step 4: Use hints (not solutions)
- Look at the pattern description
- Check the example walkthrough
- Ask: "What data structure would help here?"

### Step 5: If still stuck after 10 min
- Read the solution explanation
- Understand WHY it works
- Close it and re-implement from memory
- Rate yourself 1-2 (you learned, but didn't solve)

## Time Management

| Activity | Target | Max |
|----------|--------|-----|
| Concept review | 10 min | 15 min |
| Pseudocode (per problem) | 15 min | 20 min |
| Implementation (per problem) | 20 min | 25 min |
| Debug (per problem) | 5 min | 10 min |
| Review | 10 min | 15 min |

If you're consistently going over time:
- Simplify the problem (remove edge cases)
- Use more hints
- Focus on understanding, not speed

## Progress Tracking

After each session, update:
1. **INDEX.md** — Mark day as complete
2. **Self-rating** — Rate pattern mastery 0-5
3. **Notes** — What you learned, what was hard

Weekly review:
- Which patterns are weak?
- Do you need to repeat any days?
- Are you on track for the 42-day goal?
