## Interactive case
Two clients compete for the last available seat. Use labs/reservation-model.mjs to expose an interleaving, explicitly as an in-memory model. For a PostgreSQL task, use two disposable connections and a declared isolation level; no production database. Another case has rising pool wait with short queries and long transaction lifetimes.

## Smallest useful repair
Atomicity is not a universal isolation guarantee. Compare a read-then-write with a conditional update or appropriate lock. Discuss retry/rollback only where needed.

Give direct teaching when continued guessing would be wasteful.
